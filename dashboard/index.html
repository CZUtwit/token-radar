How the model works

The board ranks pre-token protocols from a sealed snapshot of every protocol DefiLlama tracks. A protocol is pre-token when the snapshot records no market cap, no CoinGecko id and no symbol for it. Wrapped, staked and bridged products, exchanges and versioned pools are left out: a wrapped token is not a protocol waiting on a launch of its own.

The formula

implied = TVL × category multiple × growth × maturity × breadth

category multiple = median(market cap / TVL) of the live-token
                    protocols in the same category (3+ comps, else the
                    global median), clamped to [0.05, 1.5]
growth            = 1 + clamp(7-day TVL change, −50%, +100%) × 0.5
maturity          = 0.6 + min(age in days, 1095) / 1095 × 0.4
breadth           = 1 + min(chains − 1, 4) × 0.03

Every input comes from the snapshot's own figures: TVL, seven-day growth, listing date and chains. No protocol name is ever special-cased — the same function scores every row, and each row's detail view shows its own numbers, so the arithmetic can be checked by hand. The code is impliedValue in lib/model.ts.

Farm plans

Each protocol gets six steps, built from its own record — its category, its chains, its TVL and its age. Every step states what it costs and how long it takes. Bigger protocols get a larger suggested position; younger ones get a longer hold, so the activity lands in more than one snapshot.

About this radar

This page is a static dashboard with no network: it renders from data.js, written by the same program that wrote board.json. The board covers all 40 protocols on the snapshot's watchlist, plus every other rankable pre-token protocol below the floor — including protocols above the $50M floor that the watchlist itself leaves out. The snapshot is frozen at 2026-11-14; the figures on this page are that day's, and a launch after it is not in the data.
